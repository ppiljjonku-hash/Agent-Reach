# 능력 범위

지원 여부나 결과 완전성을 판단할 때 읽습니다. 실제 액션·인자는 `agent-reach channels`가 기준입니다.

| 채널 | 범위 | 한계 |
|---|---|---|
| twitter | 검색, 프로필, 타임라인, 답글 | 반환된 답글만 포함하며 전체 답글 수집을 보장하지 않음 |
| reddit | 검색, 게시물과 상위 댓글, 서브레딧 | 전체 댓글 트리 수집을 보장하지 않음 |
| youtube | 검색, 영상 정보, 자막, 음성 전사 | 영상에 제공되는 자막만 사용. 전사는 사용자 키와 외부 API 할당량 필요 |

X·Reddit은 로컬 OpenCLI와 전용 브라우저, YouTube는 로컬 yt-dlp를 사용합니다.
설치·로컬 상태·실제 검증은 별개입니다. 실패를 외부 검색 결과로 성공 처리하지 않습니다.
인증이 필요한지는 실제 선택한 사이트 경로의 응답으로 판단합니다.
