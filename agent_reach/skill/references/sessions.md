# 세션과 전용 브라우저

로그인·로그아웃·계정 선택 또는 `NEED_LOGIN` 처리 시 읽습니다.
X·Reddit은 `~/.agent-reach/browser/profile`의 공유 전용 프로필을 사용합니다.
YouTube는 브라우저 세션을 요구하지 않습니다.

## 로컬 재사용

연결된 로컬 브라우저의 요청 사이트 쿠키만 한 번 복사합니다. 원본 브라우저는 변경하지 않고
암호 저장소를 읽지 않습니다. 여러 출처에 계정이 있으면 임의 선택하지 않고 사용자 선택을 받습니다.
`browser profiles`로 출처를 확인하고 `browser use ID`로 선택합니다.
`login twitter --import-existing` 또는 `login reddit --import-existing`은 명시적으로 다시 복사합니다.
세션 파일에는 민감한 쿠키가 있으므로 외부로 공유하지 않습니다.

## 사용자 로그인

실제 사이트 응답이 인증을 요구할 때 `login twitter` 또는 `login reddit`을 실행합니다.
사용자가 전용 창에서 직접 로그인합니다. 에이전트가 대신 로그인하거나 비밀번호를 요구하지 않습니다.
자동화 차단 시 중단하고 프로필을 바꾸어 재시도하지 않습니다.

## 로그아웃

`logout CHANNEL`은 해당 사이트의 전용 쿠키와 재사용 상태를 지웁니다. 다른 사이트와 원본 브라우저는 유지합니다.
CDP는 `127.0.0.1`에만 열립니다. 터널·포트 포워딩으로 외부에 공개하지 않습니다.
